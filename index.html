파이썬 세 개를 실제로 돌리려면

  1. 파이썬을 설치합니다. python.org 에서 받습니다. 윈도우 설치 화면에서 Add Python to PATH 를 반드시 켜세요. 안 켜면 명령어를 못 찾습니다.
  2. 저장소를 내려받습니다. GitHub 페이지 → Code → Download ZIP → 압축을 풉니다.
  3. 필요한 것을 설치합니다.
    pip install pdfplumber openpyxl
  4. 풀어 놓은 폴더에서 실행합니다. 위 각 카드의 명령어를 그대로 붙여 넣습니다.
  5. 결과는 각 과제의 output/ 폴더에 생깁니다.

세 스크립트 모두 메일을 보내지 않고 초안까지만 만듭니다. 실제 발송은 사람이 확인한 뒤 누릅니다. 사내 메일 서버로 자동 발송하려면 각 과제 README의 "실서비스 전환" 절을 보세요.

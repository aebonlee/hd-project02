# 개발일지 — 반복 업무 자동화 4종 (hd-project02)

- 프로젝트: 반복 업무 자동화 및 기존 업무 개선 (PDF 추출 · MES 메일 · SAP 엑셀 메일 · 협력업체 결품 응답 웹)
- 기획: 권도연 (생성형 AI 업무자동화 전문가과정 1차수)

- 저장소: https://github.com/aebonlee/hd-project02

## 1. 요구사항 분석

기획서는 서로 독립적인 4개 과제로 구성된다.

| 과제 | 내용 | 우선순위 |
|---|---|---|
| D | 협력업체 결품(D+4) 현황을 웹에서 응답받는 페이지 (기존: 매일 엑셀 메일 + 전화/문자 확인) | ★ 1순위 |
| A | 업체마다 양식이 다른 PDF에서 5개 항목 추출 → 엑셀 (인코텀즈는 업체별 형식 상이) | 2순위 |
| C | SAP 다운로드 엑셀 가공본 → 범위 캡처 + 첨부 메일 발송 | 3순위 |
| B | MES 라인별 진행현황 → 매일 07:00~07:30 Outlook 메일 (앞당김 빨강/지연 검정) | 3순위 |

핵심 제약: 기획자가 **개인 노트북**으로 실습 중이라 사내 시스템(SAP/MES/회사 Outlook/카카오톡 알림톡)에 접근 불가. 따라서 모든 연동 지점을 **교체 가능한 어댑터 + Mock/샘플 데이터**로 구현하고 회사 PC 적용법을 README에 명시하는 방향으로 결정했다.

## 2. 설계 결정

| 결정 | 이유 |
|---|---|
| 과제별 독립 폴더(4개) + 독립 실행 | 과제 간 의존성 제거, 하나씩 회사 환경에 이식 가능 |
| 과제 D는 단일 HTML + localStorage | 개인 환경에서 서버 없이 완결. 추후 Supabase 등으로 저장 계층 교체 |
| 과제 A는 정규식 규칙 + 업체별 설정(`vendors.json`) | 인코텀즈처럼 업체별 표기가 다른 항목을 코드 수정 없이 규칙 추가로 대응 |
| 메일은 `.eml` 초안 생성으로 대체 | 개인 환경에 Outlook COM이 없음. 회사 PC에서는 win32com 코드로 교체 (README) |
| 카카오톡 알림은 알림 로그로 대체 | 알림톡은 사업자 계약 필요. 어댑터 분리로 추후 연동 |

## 3. 구현 내역

1. **과제 D** (`taskD_shortage_web/`): 담당자 모드(엑셀 업로드·업체별 반영, 미응답/이슈/이상 없음 모니터링, 이슈 부품 CSV·엑셀 내보내기, 10시 마감 시뮬레이션→알림 로그) + 업체 모드(업체코드+비밀번호 로그인, 담당 부품만 표시, 특이사항 있음/없음 응답 — '있음' 시 사유·예상 입고일 필수). 순수 로직은 `js/logic.js`로 분리. 샘플 엑셀(5개 업체 44행) 생성기 포함.
2. **과제 A** (`taskA_pdf_extract/`): pdfplumber + 정규식 추출기, 업체별 인코텀즈 규칙 분기, 실패 시 검토필요 플래그. reportlab으로 레이아웃이 다른 샘플 PDF 3종(라벨형/표형/문장형) 생성.
3. **과제 B** (`taskB_mes_mail/`): Mock CSV → 07시 기준 계획 대비 시작 수량 차이 계산 → 앞당김 빨간색/지연 검은색 HTML 본문 + `.eml` 초안. Playwright MES 스크래핑·Outlook COM·작업 스케줄러 등록 가이드 포함.
4. **과제 C** (`taskC_sap_excel_mail/`): 엑셀 지정 범위를 셀 서식(배경색·병합 등) 반영 HTML 표로 변환해 본문 삽입, 날짜명 다른 이름 저장 후 첨부 `.eml` 생성. xlwings 이미지 캡처 대체법 README 명시.

## 4. 테스트 및 검증

- 과제 D: `node taskD_shortage_web/test/logic.test.js` **12/12 통과**, 전체 JS `node --check` 통과
- 과제 A: 샘플 PDF 3건 추출 실행 → 기대값 스크립트 대조 **전부 일치** (예: `FOB-2020-1184`, `CIF/2024/0087`, `EXW-88-0771` 업체별 형식 모두 정상 추출)
- 과제 B: 라인별 차이 수량(1라인 +80 앞당김, 2라인 -240 지연 등) 수기 계산과 일치
- 과제 C: 생성된 `.eml`을 email 모듈로 재파싱해 서식 반영 본문 + 엑셀 첨부 확인

## 5. 트러블슈팅

| 이슈 | 해결 |
|---|---|
| 개발 환경에서 pdfplumber import 오류 | `cffi` 의존성 추가 설치로 해결 (코드 변경 없음) |
| PDF 내 한글 렌더링 | reportlab UnicodeCIDFont(HYSMyeongJo-Medium) 등록으로 해결 |
| 업체별 인코텀즈 표기 상이 | 업체 코드별 정규식을 `vendors.json`으로 외부화, 신규 업체는 설정 추가만으로 대응 |

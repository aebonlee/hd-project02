# 과제 A. 업체별 상이한 PDF에서 데이터 추출 → 엑셀

협력업체들이 보내는 레이아웃이 서로 다른 PDF에서 5가지 항목을 추출해 하나의 엑셀로 만든다.

- 공통 4개 항목(값 형식 동일): **품번, 무게, 수량, 금액**
- 업체마다 표기 형식이 다른 1개 항목: **인코텀즈 번호** → `vendors.json` 의 업체별 규칙으로 분기
- 추출 실패 항목은 빈칸 + **검토필요** 플래그(해당 행 붉은 배경)

## 실행 방법

```bash
python3 taskA_pdf_extract/make_samples.py   # 레이아웃이 다른 샘플 PDF 3종 생성
python3 taskA_pdf_extract/extract.py        # sample_pdfs/ 전체 추출 → output/추출결과.xlsx
python3 taskA_pdf_extract/extract.py 특정파일.pdf   # 특정 파일만 처리
```

## 샘플 PDF 3종 (레이아웃 상이)

| 업체 | 문서 형태 | 인코텀즈 표기 예 |
|---|---|---|
| 대한정밀 | 라벨:값 나열형 인보이스 | `Incoterms : FOB-2020-1184` |
| 한빛금속 | 표 형식 납품명세서 | `INCOTERMS NO. CIF/2024/0087` |
| 세종산업 | 문장 서술형 출하 안내문 | `운송조건은 EXW (No. EXW-88-0771)` |

## 추출 전략

1. `pdfplumber` 로 텍스트 + 표 셀 텍스트 추출
2. 본문/파일명 키워드로 업체 판별 (`vendors.json` 의 `키워드`)
3. 공통 4항목: 라벨 근처 공통 정규식 → 실패 시 값 형식 단독 패턴(fallback, 표 형식 대비)
4. 인코텀즈: 업체별 정규식 패턴으로 분기
5. 실패 항목 빈칸 + `검토필요 = Y (항목명)` 기록

## 새 업체 추가 방법

`vendors.json` 의 `vendors` 에 항목 하나만 추가하면 된다.

```json
"새업체명": {
  "키워드": ["새업체명", "NEW VENDOR"],
  "인코텀즈_패턴": "정규식 (캡처그룹 1개)",
  "인코텀즈_예시": "실제 표기 예"
}
```

## LLM 보조 추출 (선택 확장)

정규식으로 인코텀즈 추출에 실패한 경우(`검토필요=Y`), 해당 PDF 텍스트를 LLM API에
"이 문서에서 인코텀즈 번호를 찾아 JSON으로 반환" 프롬프트와 함께 보내 보조 추출할 수 있다.
`extract_from_pdf()` 에서 `incoterms == ""` 인 지점이 어댑터 삽입 위치이며,
LLM 결과는 항상 `검토필요=Y` 를 유지해 사람이 최종 확인하도록 권장한다.
